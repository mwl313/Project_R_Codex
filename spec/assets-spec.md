## 2. 사운드 애셋

### 2.1 공통 스펙

| 속성 | 값 |
|------|-----|
| 포맷 | **OGG/Vorbis** |
| 샘플레이트 | 44,100 Hz |
| 채널 | **Mono** |
| 비트레이트 | 96~128 kbps (VBR) |
| 최대 길이 | 3초 이내 |

> LÖVE2D는 `.ogg`를 권장. `.wav`도 가능하지만 용량이 큼.
> `.mp3`는 특정 빌드에서만 지원되므로 피할 것.

### 2.2 효과음 목록

| 파일명 | 설명 | 길이 | 비고 |
|--------|------|------|------|
| `sfx_shot_charge.ogg` | 드래그 중 파워 축적 (루프) | 1.5s | 루프 지점 seamless |
| `sfx_shot_release.ogg` | 샷 발사 | 0.3s | 가벼운 "탁" |
| `sfx_collision_stone.ogg` | 알-알 충돌 | 0.2s | 딱딱한 충돌음 |
| `sfx_collision_wall.ogg` | 벽 충돌 | 0.2s | 낮은 둔탁음 |
| `sfx_stone_out.ogg` | 알 아웃 | 0.4s | 휘파람 + "펑" |
| `sfx_ability_activate.ogg` | 초능력 발동 (공통) | 0.6s | 고양감 있는 상승음 |
| `sfx_charge_full.ogg` | 충전 100% 도달 | 0.3s | "띵" 알림음 |
| `sfx_turn_change.ogg` | 턴 전환 | 0.3s | 전환 알림 |
| `sfx_victory.ogg` | 승리 | 2.0s | 밝고 경쾌한 팡파레 |
| `sfx_defeat.ogg` | 패배 | 2.0s | 차분한 종료음 |

**총 예상 용량:** ~500KB (10개 × ~50KB avg)

**경로:** `assets/sfx/`

## 3. 이펙트 애셋 (코드 기반 — 이미지 없음)

다음 이펙트들은 별도 스프라이트 없이 `love.graphics` + 파티클 시스템으로 구현:

| 이펙트 | 방식 | 설명 |
|--------|------|------|
| 샷 트레일 | 원형 파티클 | 샷 방향 따라 점점 작아지는 원들 |
| 충돌 이펙트 | 폭발 파티클 | 충돌 지점에서 방사형 원 |
| 메테오 낙하 | 스크린 세로줄 + 충격파 원 | 위→아래 빛줄기 + 바닥 충격파 |
| 섀도우스텝 | 텔레포트 원 | 출발점·도착점에 보라색 원 축소/확대 |
| 디바인실드 | 방패 오버레이 | 알 주변 노란색 실드 링 회전 |
| 콤보피니셔 | 타격선 + 화면 흔들 | 첫 샷 아웃 시 슬래시 라인 + 카메라 셰이크 |

**구현 위치:** `effects/effect_manager.lua` 확장  
**참고:** 기존 shockwave pulse 이펙트가 이미 구현되어 있음
