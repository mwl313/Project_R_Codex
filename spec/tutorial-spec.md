# Spec: 튜토리얼 씬

## Objective
Phase 2 폴리시 — 신규 플레이어가 기본 조작법과 초능력 시스템을 익힐 수 있는 튜토리얼을 구현한다.
애셋 불필요, 텍스트 + 기존 UI + 가상의 적 알만으로 구성.

## 튜토리얼 스텝

### Step 1: 기본 조작 — 알 배치
- 설명: "보드를 클릭해 알 7개를 배치하세요"
- 좌측에 배치 가이드 (3-2-2 포메이션 미리보기 점선)
- 7개 배치 완료 시 → 자동으로 다음 스텝

### Step 2: 드래그 & 샷
- 설명: "알을 클릭하고 드래그해서 방향과 파워를 정하세요"
- 중앙에 단일 타겟 알 (가상, 움직이지 않음)
- 플레이어 알 1개로 연습 샷
- 궤적 예측선 표시
- 타겟 맞추면 → 다음 스텝

### Step 3: 초능력 — 충전
- 설명: "매 턴 25%씩 충전돼요. 100%가 되면 초능력을 쓸 수 있어요!"
- 충전 게이지 0% → 자동으로 100%까지 충전 애니메이션
- 게이지 풀차지 + 펄스 이펙트

### Step 4: 초능력 — 발동
- 설명: "충전이 완료되면 '⚡ 발동'을 클릭하세요"
- "⚡ 발동" 버튼 클릭 유도
- 선택한 캐릭터의 초능력 발동 이펙트 재생
- 예: 나이트로드 → 알이 순간이동하는 모습

### Step 5: 완료
- 설명: "이제 준비됐어요! 친구와 대전해보세요"
- "로비로 돌아가기" 버튼

## 구현 상세

### `scenes/tutorial_scene.lua` (신규, ~250줄)
- tutorialState: "placement" | "shot" | "charge" | "ability" | "complete"
- 간소화된 보드 (미니매치)
- 왼쪽/상단에 설명 텍스트 패널
- 현재 스텝만 상호작용 가능, 나머지는 하이라이트로 표시
- 유저가 선택한 캐릭터 정보를 로비에서 params로 받음

### `app.lua` (수정, ~5줄)
- tutorial_scene 등록
- 씬 라우팅 추가

### `scenes/lobby_scene.lua` (수정, ~5줄)
- "튜토리얼" 버튼 추가
- 선택한 캐릭터 ID를 params로 전달

## Files

## Success Criteria
- [ ] 5단계 튜토리얼 순차 진행
- [ ] 배치 → 드래그샷 → 충전 → 발동 → 완료 흐름
- [ ] 모든 설명이 한글로 표시
- [ ] 언제든 ESC로 로비 복귀 가능
- [ ] 선택한 캐릭터의 초능력으로 Step 4 연출
