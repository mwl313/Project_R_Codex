# ProjectR Sound Hooks

Place optional sound files here.

## Naming Rule

- Filename must match hook id used by client runtime.
- Supported extensions (auto-detected):
- `.ogg`
- `.wav`
- `.mp3`

## Example

- Hook id: `match_result`
- Valid files:
- `assets/sounds/match_result.ogg`
- `assets/sounds/match_result.wav`

## Safety

- Missing files are allowed.
- Game continues without sound (no crash).
