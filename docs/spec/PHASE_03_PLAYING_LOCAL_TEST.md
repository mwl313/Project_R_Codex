# PHASE_03_PLAYING_LOCAL_TEST
Date: 2026-02-09

## 목적
- `PLAYING` 기본 턴 루프(턴 시작 -> 발사 입력 -> 스냅샷 정산 요청/적용 -> 다음 턴)를 수동 검증한다.

## 사전 조건
- 서버: `npm run dev` (`project_r` 루트)
- 클라이언트 2개 실행 후 방 생성/참가 완료
- `PLACEMENT_PRIVATE -> PLACEMENT_REVEAL -> CARD_SELECT`를 지나 `PLAYING` 진입

## 시나리오
1. 현재 턴 플레이어에서 내 알을 클릭 후 드래그/릴리즈한다.
2. 화면 상태 메시지에 발사 요청/수락 및 스냅샷 대기 문구가 출력되는지 확인한다.
3. 호스트 클라이언트에서 `match.turn.snapshotRequested` 이후 자동으로 스냅샷 제출이 진행되는지 확인한다.
4. 양쪽에서 `match.turn.snapshotApplied` 이후 다음 `match.turn.start`가 도착하고 턴 소유자가 반전되는지 확인한다.
5. 턴 타이머(30초) 내 발사를 하지 않아도 스냅샷 요청 경로를 통해 다음 턴으로 진행되는지 확인한다.
6. 발사한 알의 위치(또는 보드 이탈 시 생존 상태)가 스냅샷 적용 후 양쪽에서 동일하게 갱신되는지 확인한다.
7. 발사 직후 약간의 이동/충돌 감쇠 애니메이션이 보이고, 종료 후 host가 스냅샷을 제출하는지 확인한다.
8. 내 턴 시작 시 `agile` 카드 버튼을 눌러 카드 적용 후 같은 턴에 2회 발사가 가능한지 확인한다.

## 기대 결과
- 크래시 없이 턴이 반복된다.
- 비활성 턴 플레이어는 발사 입력이 거부된다.
- 서버 `error.generic`가 발생하면 클라이언트 상태가 복구되고 입력이 재시도 가능하다.
